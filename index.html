Your data, easy to save and transfer.

Cladar saves your data on your device. A JSON backup is a readable copy that you can keep or transfer; it does not automatically sync data between devices.

What's in the file

The file is named, for example, cladar_backup_YYYY-MM-DD.json and contains these sections:

  • cladar_profiles: all profiles. Each entry contains an id, personal and university details in profile, the course plan in studyPlan, grades in evaluations, and attendance in attendanceLogs. Uploaded photos and QR codes may be included as data URLs.
  • cladar_active_profile_id: identifies the profile that was selected when the backup was created.
  • cladar_profile, cladar_study_plan, cladar_evaluations, and cladar_attendance_logs: copies of the active profile's data, also included for compatibility.
  • Other top-level sections: cladar_events for events; cladar_course_details for course details, exam sessions, and links; cladar_course_attendance for course attendance; and cladar_courses_other for links and notes for other courses.
  • cladar_homeworks, cladar_tasks, and cladar_notes: homework, tasks, and notes; cladar_weekly_plan: your weekly routine; cladar_theme: light or dark theme.

Use it on another device

  1. On the original device, open Settings → Backup & Data Management and choose Share Backup (JSON) or Export Data (JSON).
  2. Send or save the file using a private method, such as AirDrop, Files/iCloud Drive, or a personal file storage service.
  3. On the new device, open Cladar, choose Import Data (JSON), and select the file. If you copied the JSON text, choose Paste Backup (JSON).

Importing replaces the corresponding data already on the device; it does not merge the two backups. Export the destination device's data first if you want to keep it.

Multiple profiles in one backup

You don't need to export them one at a time: cladar_profiles contains the full list. After importing, you can choose a profile from Cladar's profile selector. Importing replaces the existing profile list with the one in the file.

Example structure

This simplified example shows two profiles and the active profile. A real backup includes the actual records and all the other fields listed above.

{
  "cladar_profiles": [
    {
      "id": "profile_ada",
      "profile": { "name": "Ada", "mat": "DEMO-01" },
      "studyPlan": [],
      "evaluations": [],
      "attendanceLogs": []
    },
    {
      "id": "profile_luca",
      "profile": { "name": "Luca", "mat": "DEMO-02" },
      "studyPlan": [],
      "evaluations": [],
      "attendanceLogs": []
    }
  ],
  "cladar_active_profile_id": "profile_ada",
  "cladar_events": [],
  "cladar_homeworks": [],
  "cladar_tasks": [],
  "cladar_notes": []
}

Privacy: JSON is readable, unencrypted text and may contain personal information, grades, and notes. Keep it somewhere private and share it only with people or devices you trust.

Get started with Cladar.

For Android

Download the latest Cladar APK from GitHub Releases and open it on your device to install.

Android may ask you to allow app installs from your browser or file manager.

Use the web app

Open Cladar, then add it to your device from the browser menu:

  1. Android: choose “Install app” or “Add to Home screen.”
  2. iPhone or iPad: in Safari, tap Share, then “Add to Home Screen.”
  3. Mac: use the install option in Chromium browsers, or “Add to Dock” in supported Safari versions.
