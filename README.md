# Cladar — Academic & Daily Management System

Cladar is a lightweight, offline-first web application optimized for mobile devices and Android WebView. Built for university students, it unifies academic tracking, course planning, daily scheduling, and task management into a single responsive interface.

## Core Features

- **Academic Analytics**: Track completed ECTS/CFU, official weighted GPA and provisional averages (including partial exams).
- **Study Plan Management**: Structure degree requirements by academic year and semester, paired with integrated grade recording.
- **Digital Student Identification**: Customizable student profile featuring matriculation data and dynamic QR code generation.
- **Daily Schedule & Routine**: Hour-by-hour location-based timetable and configurable weekly routines.
- **Tasks, Notes & Homework**: Markdown and LaTeX math syntax support ($\lim_{x \to 0} \frac{\sin x}{x} = 1$) with gesture-based task management.
- **Calendar & Countdown Timers**: Visual monthly overview with real-time countdowns for upcoming exams and deadlines.
- **Offline Data Storage**: Full local storage with JSON import/export capabilities, integrated via Kotlin JavascriptInterface for native Android file exports.
